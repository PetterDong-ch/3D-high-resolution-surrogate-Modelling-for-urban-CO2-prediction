# External Data Contract

The model package is portable and does not require the original personal
experiment directories. Raw PALM data are external because of size and access
restrictions. Authorised users should request them from
`l.li20@imperial.ac.uk`.

## Required Inputs

Set `CAMDEN_JOBS_ROOT` or place the raw jobs at
`external_data/camden/JOBS`. Each selected `z##_camden2019##` job must retain
its original `INPUT/` and `OUTPUT/` NetCDF files, including dynamic forcing,
chemistry/emissions, 3-D output and static/topography fields.

Stage-2 sampling also needs V40 coordinate metadata. Either place the V40
coordinate sidecar at `external_data/v40_coordinate_sidecar`, or set
`V40_COORDINATE_SIDECAR_ROOT`. It can be regenerated by the companion V40
reproducibility package.

## Generated Inputs

The following are regenerated locally and must not be downloaded from old
experimental paths:

```text
generated/stage1_manifest/
generated/stage1_cache/
generated/stage2_manifest/
generated/stage2_cache/
generated/previous_co2_sidecar/
generated/full_domain_context_sidecar/
```

All normalization statistics are stored inside generated cache manifests. The
scripts use deterministic sample selection with seed 42.
