# Evaluation-Only Use

Obtain authorised Camden PALM data from `l.li20@imperial.ac.uk`, pull the Git
LFS checkpoints, and create the locked environment from `environment.yml`.
Then, from this package directory, run:

```bash
python scripts/verify_package.py --data-root external_data
bash scripts/prepare_camden_data.sh
bash scripts/reproduce_camden_report_evaluation.sh
```

The evaluator loads `checkpoints/best_model.pt` and writes the reproduced
metrics and visualisations under `reproduced/v40_report_evaluation/`. The expected
40-sample values and checkpoint SHA-256 hash are recorded in
`reproducibility_manifest.json`.

The model requires the previous CO2 field, its gradients, V40 context features,
coordinate metadata and texture sidecar. These are generated by the preparation
script and cannot be inferred from the checkpoint alone.
